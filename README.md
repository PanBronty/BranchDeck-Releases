# BranchDeck Releases

Official BranchDeck evaluation downloads for Windows.

Download the latest installer or portable build from
[Releases](https://github.com/PanBronty/BranchDeck-Releases/releases/latest). SHA-256 checksum files
are provided beside both executables.

BranchDeck is currently distributed under a free evaluation licence. The application source code
is maintained separately and is not published in this repository.

BranchDeck is not code-signed yet, so Windows SmartScreen may show an unknown-publisher warning.
Verify the downloaded executable against its `.sha256` file before running it.
